# Expense Tracker

A small React app to track personal expenses. Built step by step, one small feature at a time.

## Tech

React 19, Vite, JavaScript, localStorage (no backend)

## Run locally

```
npm install
npm run dev
```

## Plan

Add expenses, list and delete them, totals, filters by category and month, summary per category, simple chart, responsive layout, live demo on GitHub Pages.
